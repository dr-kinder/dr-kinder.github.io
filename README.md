# dr-kinder.github.io

Jesse Kinder's public course website. Built with [Quarto](https://quarto.org), published to
GitHub Pages automatically on every push to `main` (see `.github/workflows/publish.yml`).

This repo is **public** — see the content-clearance rule in
`../classes/fresh-start/website/notes.md` (private repo) before adding anything here. Never
commit student data, grades, or unreviewed copyrighted material.

## Local preview

quarto preview
